# Dashboard Design

## Primary Users

- Marketing: content opportunities and editorial calendar
- Sales: talking points and discovery questions
- Leadership: executive briefings and market movement
- Customer Success: customer-facing context and renewal risk themes
- Analysts: source health, evidence, scoring, and review queue

## Navigation

- Daily Digest
- Signals
- Trends
- Content Opportunities
- Sales Enablement
- Executive Briefings
- Review Queue
- Sources
- Reports
- Settings

## Daily Digest View

Top area:

- Date
- Total articles ingested
- Signals surfaced
- Average score
- High-risk developments

Main list:

- Headline
- Source
- Date
- Score
- Signal type
- Business impact
- Suggested action
- Review status

## Signal Detail View

Sections:

- Source metadata
- Evidence excerpts
- Score breakdown
- TADA Perspective
- Detect, Decide, Do
- Linked content opportunities
- Linked trend cluster
- Review history

## Trend Memory View

Charts:

- Trend velocity over time
- Topic frequency
- Source contribution
- Emerging versus declining themes

Recommended filters:

- Time period
- Category
- Source
- Signal type
- Minimum score

## Review Queue

Columns:

- Item type
- Signal
- Score
- Owner
- Status
- Last updated
- Reviewer

Actions:

- Approve
- Reject
- Request revision
- Assign reviewer
- Add comment

## Design Guidance

The dashboard should feel like an enterprise intelligence workspace:

- Dense but readable
- Fast filtering
- Clear evidence links
- Review status always visible
- No decorative marketing layout
- Emphasis on decision readiness
