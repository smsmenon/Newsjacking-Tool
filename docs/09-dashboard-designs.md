## Dashboard 1 — Executive Portal Dashboard

### Purpose
The first screen every TADA user sees. Surfaces the most critical intelligence for leadership in under 60 seconds.

### Layout
```
[Header: 56px] [Sidebar: 240px] [Content: fluid, max 1400px centered]

ROW 1 — KPI Strip (4 cards, equal width, 24px gap)
ROW 2 — [Top Signals: 60%] [Right Rail: 40%]
         [Competitor Pulse | Market Sentiment]
ROW 3 — [Recommended Actions: 100%]
```

### Components & Data

**KPI Strip Cards:**
| Card | Metric | Color | Data Source |
|------|--------|-------|-------------|
| Signals Today | Count + delta | Blue | `/executive/dashboard` |
| Critical Risks | Count + new | Red | `/signals?urgency=critical` |
| Opportunities | Count + new | Green | `/signals?type=opportunity` |
| Pending Review | Count | Amber | `/review/queue` |

**Top Signals Panel:**
- Shows 5 highest-scoring signals from last 24h
- Each card: title, source count, confidence %, urgency badge, 1-line summary
- Sorted by composite score descending
- "View All Signals" CTA at bottom

**Competitor Pulse Rail:**
- Last 5 competitor events chronologically
- Colored by event type (launch=blue, funding=green, acquisition=purple)
- Click opens competitor event detail modal

**Market Sentiment Gauge:**
- Radial gauge: Bearish ← → Bullish
- Computed from sentiment scores across last 48h of content
- Sub-gauges per sector (Supply Chain, Procurement, Manufacturing)

**Recommended Actions Panel:**
- 3–5 prioritized actions generated by Recommendation Engine
- Tagged by team [Marketing] [Sales] [Leadership] [CS] [Product]
- Each with estimated effort (Quick / Medium / Strategic)
- One-click to mark as "noted"

### Interactions
- Signal card click → Signal Detail page (no new tab)
- KPI cards → navigate to relevant list page
- Competitor event click → modal with full event details + "Generate Response" button
- Actions panel "noted" → removes from list, logs to audit trail

### Refresh Strategy
- Auto-refresh every 5 minutes (SWR with `refreshInterval: 300000`)
- Manual refresh button top-right
- Stale data indicator if >15 min old

## Dashboard 6 — Human Review Queue Dashboard

### Purpose
Manage all AI-generated outputs awaiting human approval before any use.

### Layout
```
ROW 1 — [Queue Metrics: 4 KPI cards]
ROW 2 — [Tab Filter: Insights | Recommendations | Content | Briefings | All]
ROW 3 — [Priority filter] [Assigned filter] [Date filter]
ROW 4 — [Review Item Cards: stacked list]
```

### Queue Metrics (KPI Row)
| Card | Value | Color |
|------|-------|-------|
| Awaiting Review | 12 | Amber |
| Approved Today | 8 | Green |
| Avg Review Time | 4.2h | Blue |
| Rejected (7d) | 3 | Red |

### Review Item Card
```
┌──────────────────────────────────────────────────────────────┐
│ [Type Badge] [Priority Badge]              [Item ID]          │
│ Title of AI-generated content                                 │
│ Generated: Jun 16, 2026 · By: TADA Perspective Agent         │
│ Signal: Tariff Escalation #041                               │
│                                                               │
│ ┌───────────────────────────────────────────────────────┐   │
│ │ Preview (first 200 chars of generated content)...     │   │
│ └───────────────────────────────────────────────────────┘   │
│                                                               │
│ [👁 View Full]  [✅ Approve]  [❌ Reject]  [↩ Request Edit] │
└──────────────────────────────────────────────────────────────┘
```

**Approve Flow:** Click → confirm dialog → status = `approved` → notification sent
**Reject Flow:** Click → required reason field → status = `rejected` → logged with reason
**Request Edit Flow:** Click → text field for specific feedback → status = `revision_requested` → re-queues to agent

## Dashboard 7 — ROI & Analytics Dashboard

### Purpose
Demonstrate and track the value TADA's intelligence platform delivers.

### Layout
```
ROW 1 — [Date Range Selector: full width]
ROW 2 — [4 Primary KPI Cards]
ROW 3 — [Signal Volume Chart: 60%] [Top Topics: 40%]
ROW 4 — [Source Performance: 50%] [Content Pipeline Stats: 50%]
ROW 5 — [Team Usage Breakdown: 100%]
```

### Charts Specification

**Signal Volume Over Time (Recharts AreaChart):**
- X: Daily/Weekly toggle
- Y: Signal count
- Series: Total signals, Critical signals (stacked or overlaid)
- Tooltip: Date, total count, breakdown by urgency
- Color: Blue fill with 0.2 opacity, blue stroke 2px

**Top Topics Bar Chart (Recharts HorizontalBarChart):**
- Y: Topic names (top 10)
- X: Mention count
- Color: Single blue `#3B82F6`
- Click: Filters intelligence explorer to that topic

**Source Performance Table:**
- Columns: Source Name | Articles | Signals Generated | Avg Score | Trust Score | Health
- Sortable by any column
- Health indicator: Green (healthy) / Amber (slow) / Red (down)

**Research Hours Saved:**
- Formula: `articles_collected × 0.5h + signals_detected × 2h + briefings_generated × 4h`
- Shown as: number + dollar equivalent (assuming $150/hr analyst rate)
- Year-to-date cumulative counter

## Dashboard 8 — Knowledge Graph Dashboard

### Purpose
Visualize relationships between companies, technologies, trends, risks, and signals.

### Layout
```
ROW 1 — [Entity Type Filter Pills] [Search: "Find entity..."] [Layout ▾]
ROW 2 — [Graph Canvas: 70%] [Entity Detail Panel: 30%]
```

### Graph Canvas (React Flow)

**Node Styles by Entity Type:**
| Type | Shape | Color | Size |
|------|-------|-------|------|
| Company | Circle | `#3B82F6` | 40px |
| Technology | Rounded rect | `#8B5CF6` | 36px |
| Trend | Diamond | `#F97316` | 44px |
| Risk | Hexagon | `#EF4444` | 38px |
| Geography | Pill | `#10B981` | 32px |

**Edge Styles:**
- Thickness: proportional to relationship strength score
- Color: `#374151` default, `#3B82F6` on hover
- Label: relationship type (small, only on hover/zoom)

- Click node → Entity Detail Panel updates
- Double-click → expand to show all related nodes

**Entity Detail Panel:**
- Entity name + type badge
- Description
- Properties (industry, founded, HQ, etc.)
- Stats: # signals, # articles, # relationships
- Related entities list (top 5 by strength)
- Recent articles mentioning this entity

## Dashboard 10 — Source Health Dashboard

### Purpose
Monitor the health and quality of all 50+ intelligence sources.

### Layout
```
ROW 1 — [Health Summary: 3 KPI cards]
ROW 2 — [Source Table: full width, sortable]
ROW 3 — [Collection Volume Chart: 60%] [Source Discovery Queue: 40%]
```

### Health Summary KPIs
| Card | Metric | Color |
|------|--------|-------|
| Sources Active | 52 / 54 | Green |
| Sources Down | 2 | Red |
| Avg Collection Lag | 1.4h | Blue |

### Source Table

**Columns:**
| Column | Type | Notes |
|--------|------|-------|
| Name | Text + logo | Linked to source URL |
| Type | Badge | RSS / API / Scrape / Social |
| Category | Badge | Manufacturing / SC / Procurement / etc. |
| Trust Score | Score bar | 0–100 |
| Articles (7d) | Number | Collection volume |
| Avg Score | Number | Quality of collected content |
| Last Collected | Timestamp | Relative time |
| Health | Status dot | Green/Amber/Red |
| Actions | Buttons | Pause / Edit / Remove |

**Row Highlighting:**
- Red background tint: source down (health = red)
- Amber background tint: source degraded (no new articles in 24h)

### Source Discovery Queue
- Shows suggested new sources (from Autonomous Discovery Engine)
- Each row: URL, suggested category, trust estimate, [Approve] [Reject]
- "Approve" → adds to active sources, triggers first collection
