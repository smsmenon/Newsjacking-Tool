# **SECTION 3: LINKEDINCONTENT PUBLISHING CHECKLIST** 

## **CHECKLIST** 

### **1. Before You Write** 

- Does this post fit the established 3–4 topic lane? 

- Is there one clear idea, not three things loosely stapled together? 

- Does this post position the reader/customer as solving a problem, or does it position TADA as the hero? 

- Monthly theme confirmed — does this align? Does it reference previous month's narrative? 

- For articles: One core thesis + three arguments identified + forward-looking close outlined 

- Check which of the 10 editorial principles does this reinforce 

### **2. Structure** 

- Strong first 1–2 lines/hook that make someone stop scrolling (this drives "see more" expansion, which feeds dwell time) 

- Content that rewards actual reading — a framework, a number, a specific example — not just a vibe 

- Fits one mobile screen before "see more" — all critical content visible without expansion 

- No external link in the post body (put it in the first comment if needed — links cut reach ~60%) 

- Word count: Posts 150–250 words | Articles 1,200–1,500 words 

- Write at 7th grade reading level — verify at hemingway.com 

- 3–5 specific, on-topic hashtags — placed at the end of the post 

- Doesn't read as AI-generated: Avoid stacked short phrases with excessive punctuation, generic sentence structure, or probability language ("may," "could potentially") 

### **3. Format Specifics** 

- Consider whether this is better as a document/carousel than plain text (currently the highest-performing format by a wide margin) 

### **3.1. If document/carousel:** 

- 10–15 slides maximum 

- Each slide has a single point 

- First slide is the hook (curiosity gap or pattern interrupt) 

- Last slide has a clear takeaway or CTA question 

### **3.2. If video:** 

- 30–90 seconds max 

- Paired with an equally strong text post (never video-only) 

- Say something in the first 10 seconds that connects with the target audience 

- Raw/unscripted founder or exec voice preferred 

- Captions burned in or auto-generated (most LinkedIn users scroll muted) 

### **3.3. If LinkedIn Live:** 

- Scheduled title is clear (panel name, topic, attendee value) 

- 45–60 min duration 

### **4. Pre-Publish Checklist** 

- Timing optimized for audience: Tue–Thu, 10–11 AM CT 

- Guha, Harsh, Ravi, Sid, Brian, Kiran set to receive comment recommendations at publish 

- Corporate page reposts scheduled for 3–4 hours post-publish (link in post body, NOT native repost) 

- For articles: TADA website republication scheduled 2–3 weeks post-publish with canonical tag + author bio + HubSpot CTA 

- Legal/compliance pass: If fictional composite, labeled clearly; no unverified claims; tag external partners/clients only when directly referenced (never internal team in post body); anonymize customer mentions unless explicitly approved 

### **5. Publish/Golden Hour (0–90 minutes)** 

- Trigger "notify employees" (3-dot menu) so employees can engage early 

- Reply to every comment within ~60 min with: 

   - Appreciation/validation of their point 

   - Added value (new insight, related framework, example) 

   - Follow-up question to extend the thread 

   - Length: 3–5 sentences, 15+ words minimum 

- Leadership engagement active: Guha, Harsh, Ravi, Sid, Brian, Kiran engaged with substantive comments within first 60 min (drives early distribution boost) 

- Never edit the post during this window — LinkedIn flags edits as manipulation; distribution resets 

### **6. Ongoing Post Management + Month-End Review** 

- Repurposing: Flag high-performers (hook, format, topic) → extract 5–10 clips if Live/video → create 3+ variations of 2x+ engagement pieces (alternate hooks), reposting every 2–3 months for new followers. 

- Comment threads mined: High-quality replies may become future post ideas or case study testimonials 

- If we don't have proof of something, lean on third-party sources — e.g., "Forbes says homeowners have 38x bigger net worth than renters." Tag the publication on LinkedIn for them to repost 

- Talk to 1 person; call your avatar out (make it personal, not generic) 

- **Month-End Performance Review (30 min):** Impressions, comments, reposts, dwell time, newsletter opens/growth, website traffic, HubSpot CTA clicks logged 

- Tie-breaker applied: Would a first-time subscriber find this most valuable? 

- Months 1–4 insights inform theme sequencing for Months 5–12
